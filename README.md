# Marb’s List

A small, responsive landing page for Marb’s List in Cambridge, Massachusetts.

Email: marbslist@gmail.com

## Publish

In repository **Settings → Pages**, choose **Deploy from a branch**, **main**, and **/(root)**, then click **Save**.

The public website will be https://jacooba.github.io/marb/ once GitHub Pages finishes deployment.

## Edit

Edit `index.html`. Styles and the email-composer script are included in that file; no build or dependencies are required. The form opens a prefilled email to Marb. It does not upload or store visitor information.
